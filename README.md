# jogo-do-milhao
Projeto desenvolvido como trabalho final da disciplina de Programação 1, utilizando a linguagem C.

Sobre o projeto

O Jogo do Milhão é um jogo de perguntas e respostas inspirado em programas de quiz. O projeto foi desenvolvido com o objetivo de aplicar na prática conceitos de lógica de programação, estruturas de dados, funções, arquivos e geração de números aleatórios.

O jogo possui um banco de perguntas dividido em três níveis de dificuldade e diferentes modos de jogo.

Funcionalidades
Modo Clássico — 15 perguntas com progressão de dificuldade
Modo Relâmpago — 10 perguntas com limite de tempo
Modo Sobrevivência — continue enquanto acertar
Modo Prática — escolha o nível de dificuldade para praticar

Como executar

Compile o projeto utilizando um compilador C, como o GCC:

gcc jogodomilhao.c -o jogodomilhao

Depois, execute:

./jogodomilhao

No Windows, o executável pode ser iniciado com:

jogodomilhao.exe
Contexto acadêmico

Projeto desenvolvido durante a graduação em Ciência da Computação na Universidade Estadual do Norte do Paraná (UENP), como trabalho final da disciplina de Programação 1.
